# mailslot (GTK)

The GTK 4 and libadwaita app for Mailslot, a private file drop: share a secret link, receive files with a SHA-256 checksum, and send files to another Mailslot. Nothing is ever served back.

The app is a thin shell over `mailslot-core`. See the project README for installation and use.
