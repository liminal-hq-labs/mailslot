# Mailslot 0.1.0

First preview release.

- Receive files by link: a web upload page that works on phones, `curl -T`, and the Mailslot client.
- Files land in a folder you choose with a SHA-256 checksum, and nothing is served back.
- Send files and folders from the Send page or `mailslot-cli`, with resumable uploads, retry and duplicate detection.
- Link expiry, size and quota limits, bad-token lockout, and optional HTTPS with a key pin.
- Optional UPnP port mapping that is time-limited, visible and removed on stop.
- Packages: Flatpak, AppImage, deb, rpm, Arch, and a static `mailslot-cli` tarball.
